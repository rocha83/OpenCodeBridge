# Rochas.AI.Manager.Core

Core SDK of the Rochas.AI.Manager platform.

## What is included
- Domain (entities, base classes, contracts)
- Application (services, tools, helpers)
- Infrastructure (AppDb, ReportService, hasher)
- TrainingEngine (numeric backend + runner)

## Usage
```bash
dotnet add package Rochas.AI.Manager.Core
```
